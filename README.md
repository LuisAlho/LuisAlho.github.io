# Luis Alho - Personal Portfolio 🌐

This repository contains the source code for my personal portfolio website, hosted via GitHub Pages. The goal of this site is to showcase my skills, projects, and journey as a Back-End Developer specializing in Java, Spring Boot, and Microservices.

---

## 🛠️ Built With

* **HTML5** - Semantic markup structure.
* **Tailwind CSS** - Modern, utility-first CSS framework for a responsive and clean dark-mode UI.
* **FontAwesome** - High-quality developer icons.
* **GitHub Pages** - Fast and reliable free hosting directly from this repository.
